# 里番自动刮削功能实现方案 — v2.5.1 → v3.0.0

## Context

用户使用绿联4800plus NAS，下载的里番需要在影视中心中正确显示海报、简介、标签等元数据。绿联影视中心默认使用TMDB刮削，但TMDB对里番/成人动画覆盖极差，几乎无法识别。解决方案是在下载完成后自动生成NFO元数据文件和JPG封面图片，让绿联影视中心通过读取本地NFO来显示完整的影片信息。

项目已经从hanime1.me获取了完整的视频元数据（title, subtitle, cover_url, tags, studio, description, upload_date等），这些数据完全足够生成NFO文件，无需额外外部数据源作为必须依赖。

---

## 一、核心设计

### 1.1 刮削流程

```
下载完成 → 自动/手动触发刮削
  → 扫描番剧目录，收集所有视频文件和video_id
  → 从VideoService获取每个视频的元数据
  → 生成NFO文件（tvshow.nfo / movie.nfo + 单集.nfo）
  → 下载/转换封面为JPG格式（poster.jpg）
  → 可选：重命名视频文件为S01E01格式
  → 可选：重组为Season目录结构
```

### 1.2 两种刮削模式

**电视剧模式（TV Show，默认）**：适用于多集系列番剧
```
/番剧系列名/
├── tvshow.nfo              # 剧集总信息
├── poster.jpg              # 剧集海报（JPG！）
├── fanart.jpg              # 背景图
├── Season 01/
│   ├── S01E01.mp4
│   ├── S01E01.nfo          # 单集信息
│   ├── S01E01-thumb.jpg    # 单集缩略图
│   ├── S01E02.mp4
│   ├── S01E02.nfo
│   └── ...
```

**电影模式（Movie）**：适用于单集OVA
```
/番剧名 (年份)/
├── 番剧名 (年份).mp4
├── movie.nfo
├── poster.jpg
├── fanart.jpg
```

### 1.3 绿联NAS关键限制
- **图片必须用JPG格式**（PNG不被识别！）
- **NFO文件**：电视剧用`tvshow.nfo`，电影用`movie.nfo`或`<文件名>.nfo`
- **文件命名**：电视剧推荐`S01E01`格式
- 需在影视中心开启"优先本地信息"选项

### 1.4 数据映射（项目已有 → NFO）

| 项目字段 | NFO字段 | 说明 |
|---|---|---|
| `VideoDetail.title` | `<title>` / `<originaltitle>` | 番剧系列名 |
| `VideoDetail.subtitle` | 单集`<title>` | 集名 |
| `VideoDetail.description` | `<plot>` | 剧情简介 |
| `VideoDetail.studio.name` | `<studio>` | 制作公司 |
| `VideoDetail.tags[].name` | `<genre>` / `<tag>` | 标签 |
| `VideoDetail.upload_date` | `<premiered>` / `<year>` / `<aired>` | 首播日期 |
| `VideoDetail.cover_url` | `poster.jpg` | 封面图 |
| `VideoDetail.video_type.name` | `<genre>` | 视频类型 |

### 2.3 刮削服务核心方法 `scrape_service.py`

```python
class ScrapeService:
    async def scrape_series(series_name, scrape_mode, is_rename_file, is_reorganize_directory) -> ScrapeResult
    async def auto_scrape_after_download(video_id)  # 下载完成自动调用
    async def scrape_all_series(...) -> List[ScrapeResult]  # 批量刮削
    def generate_tvshow_nfo(series_title, metadata_list) -> str  # tvshow.nfo XML
    def generate_episode_nfo(video_detail, season, episode) -> str  # 单集.nfo XML
    def generate_movie_nfo(video_detail) -> str  # movie.nfo XML
    async def generate_poster(series_dir, cover_url) -> bool  # poster.jpg
    async def generate_episode_thumb(video_detail, path) -> bool  # 缩略图
    def rename_video_to_season_format(series_dir, video_files) -> List[str]  # 重命名
    def reorganize_to_season_directory(series_dir, renamed_files) -> bool  # 目录重组
    def _scan_series_directory(series_dir) -> List[Dict]  # 扫描目录
    def _determine_episode_number(video_files) -> Dict[str, int]  # 确定集号
    def _sanitize_nfo_text(text) -> str  # 清理XML非法字符
```

### 2.4 NFO模板

**tvshow.nfo**：
```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<tvshow>
    <title>番剧名称</title>
    <originaltitle>原名</originaltitle>
    <plot>剧情简介</plot>
    <mpaa>NC-17</mpaa>
    <premiered>2026-01-01</premiered>
    <year>2026</year>
    <studio>制作公司</studio>
    <genre>动画</genre>
    <genre>成人</genre>
    <tag>标签1</tag>
    <uniqueid type="hanime" default="true">{video_id}</uniqueid>
    <thumb aspect="poster" preview="poster.jpg">poster.jpg</thumb>
    <fanart><thumb preview="fanart.jpg">fanart.jpg</thumb></fanart>
</tvshow>
```

**episodedetails**：
```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<episodedetails>
    <title>第1集</title>
    <season>1</season>
    <episode>1</episode>
    <plot>本集简介</plot>
    <aired>2026-01-01</aired>
    <thumb aspect="thumb" preview="S01E01-thumb.jpg">S01E01-thumb.jpg</thumb>
</episodedetails>
```

### 2.5 API端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/scrape/config` | 获取刮削配置 |
| PUT | `/api/scrape/config` | 更新刮削配置 |
| POST | `/api/scrape/series` | 手动刮削指定番剧 |
| POST | `/api/scrape/batch` | 批量刮削 |
| GET | `/api/scrape/preview/{series_name}` | 预览刮削效果（不执行） |
| GET | `/api/scrape/scan` | 扫描可刮削的番剧系列列表 |

### 2.6 配置项

```python
SCRAPE_MODE: str = "tv_show"               # tv_show / movie
AUTO_SCRAPE_AFTER_DOWNLOAD: bool = True    # 下载完成后自动刮削
SCRAPE_RENAME_FILE: bool = True            # 重命名为S01E01格式
SCRAPE_REORGANIZE_DIRECTORY: bool = True   # 重组为Season目录
SCRAPE_CONVERT_COVER_JPG: bool = True      # 转换封面为JPG
```

## 五、验证方案

1. 下载一个视频，验证自动刮削是否触发
2. 检查番剧目录下是否生成了 tvshow.nfo、poster.jpg
3. 检查 Season 01/ 目录下是否有 S01E01.mp4、S01E01.nfo、S01E01-thumb.jpg
4. 确认 poster.jpg 确实是 JPG 格式而非 PNG
5. 在前端设置页面验证刮削配置可保存和加载
6. 在前端下载页面验证手动刮削和批量刮削按钮可用
7. 验证深浅主题下刮削相关UI正确显示
8. 验证手机端布局适配
